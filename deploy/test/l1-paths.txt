# The changes that need a level-1 (L1) run: the real packages, with the mandatory access control
# enforcing, in the VMs on the maintainer's machines (docs/testing.md, "Which changes need an L1 run";
# R1 decision 7 in docs/decisions.md). Read by hack/ci/l1-required.sh, which the `l1-paths` CI job runs
# and which prints the verdict in the job summary; tested by deploy/test/l1paths_test.sh.
#
# Format: one bash pattern per line, matched against the path from the repository root; `*` also
# matches `/`. A leading `!` excludes. Blank lines and lines starting with `#` are ignored. The LAST
# line that matches a path decides, so an exclusion must come after the pattern it carves out of.
# A path that matches nothing does not need an L1 run.
#
# Every release candidate runs all L1 targets whatever this file says.
