Install it on the host

Write the token to the agent's token file (default /etc/clamfleet/token, readable by the agent user, for example mode 0640 owner root group clamfleet), then restart the agent. The token appears on this page once only; the commands below do not repeat it.

sudoedit /etc/clamfleet/token          # paste the token above, one line
sudo chown root:clamfleet /etc/clamfleet/token
sudo chmod 0640 /etc/clamfleet/token
sudo systemctl restart clamfleet-agent

Done, back to the hosts
