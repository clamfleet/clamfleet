element: two deliberate clicks, no JavaScript (the CSP allows none inline). Delete also needs the host name typed. */}} {{define "host_actions"}}
Rotate token…

Issues a new token and shows it once. The old token stops working at once{{if not .HasToken}}; this also re-enables the host{{end}}.

{{if .HasToken}}
Revoke token…

The agent can no longer report. History is kept; the host leaves the fleet page.

{{end}}
Delete host…

Deletes the host with all its reports, events and history. This cannot be undone.

{{end}}
